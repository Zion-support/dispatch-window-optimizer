# Dispatch Window Optimizer

> AI scheduling of service windows that maximizes first-time-fix and customer satisfaction.

Optimizes appointment windows using traffic, parts availability, technician skills and historical job duration.

**Live:** https://ziontechgroup.com/dispatch-window-optimizer/  
**Network hub:** https://github.com/Zion-support/zion-app-network

## Features
- Smart window proposals with first-time-fix probability
- Customer self-rescheduling portal links
- Parts-aware scheduling via [zion-ai-spare-parts-finder](https://github.com/Zion-support/zion-ai-spare-parts-finder)
- Route integration with [route-density-planner](https://github.com/Zion-support/route-density-planner)
